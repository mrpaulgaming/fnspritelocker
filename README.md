# 🎮 Introduction



## 🇮🇹 Italiano



Fortnite Sprite Locker è un'applicazione web completamente offline progettata per permettere ai giocatori di Fortnite di collezionare, organizzare e monitorare tutti gli Sprite disponibili nel **Capitolo 7 • Stagione 3**.



L'applicazione nasce con l'obiettivo di offrire un'esperienza simile al Locker ufficiale di Fortnite, mantenendo però una gestione avanzata della propria collezione.



Ogni Sprite possiede:



- Varianti collezionabili

- Informazioni dettagliate

- Percentuali di ottenimento

- Bonus esclusivi

- Stato Mastered

- Indicazione della rarità

- Progressione individuale



Tutti i dati vengono salvati automaticamente nel browser e possono essere esportati, condivisi oppure ripristinati in qualsiasi momento.



Il progetto è stato sviluppato interamente in HTML, CSS e JavaScript senza utilizzare framework esterni, rendendolo estremamente leggero, veloce e facilmente modificabile.



---



## 🇬🇧 English



Fortnite Sprite Locker is a fully offline web application designed to help Fortnite players collect, organize and track every available Sprite from **Chapter 7 • Season 3**.

- Collectable variants

- Rarity information

- Individual completion progress

➕ Adding New Sprites

## 🇮🇹 Italiano

Aggiungere un nuovo Sprite richiede solamente pochi passaggi.

Ogni Sprite è definito all'interno dell'array `SPRITES`.

Ogni oggetto deve contenere:

```javascript
{
    id:"",
    name:"",
    passive:"",
    rarity:"",
    variants:[],
    unreleasedVariants:[],
    unreleased:false,
    spawn:{}
}
```

### Campi

| Campo | Descrizione |
|--------|-------------|
| id | Identificatore univoco |
| name | Nome dello Sprite |
| passive | Abilità Passiva |
| rarity | Rare, Epic, Legendary o Mythic |
| variants | Varianti disponibili |
| unreleasedVariants | Varianti non ancora uscite |
| spawn | Percentuali di ottenimento |

Successivamente sarà sufficiente aggiungere le immagini nella cartella:

```
assets/sprites/
```

seguendo il formato

```
sprite_variant.png
```

Ad esempio:

```
water_basic.png
water_gold.png
water_galaxy.png
```

---

## 🇬🇧 English

Adding a new Sprite only requires a few simple steps.

Every Sprite is stored inside the `SPRITES` array.

Required structure:

```javascript
{
    id:"",
    name:"",
    passive:"",
    rarity:"",
    variants:[],
    unreleasedVariants:[],
    unreleased:false,
    spawn:{}
}
```

### Fields

| Field | Description |
|--------|-------------|
| id | Unique identifier |
| name | Sprite name |
| passive | Passive ability |
| rarity | Rare, Epic, Legendary or Mythic |
| variants | Available variants |
| unreleasedVariants | Upcoming variants |
| spawn | Spawn rates |

Then place every image inside

```
assets/sprites/
```

using the following naming convention:

```
sprite_variant.png
```

Example:

```
water_basic.png
water_gold.png
water_galaxy.png
```
