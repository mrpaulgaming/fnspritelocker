# 📤 Share & Export Guide

Fortnite Sprite Locker includes multiple tools for backing up, exporting and sharing your collection.

Whether you want to save your progress, showcase your collection, or transfer it to another device, every feature is designed to work entirely offline.

- PNG Export
- JSON Backup
- JSON Restore
- Share Collection
- How Sharing Works
- Best Practices

---

# 🖼️ PNG Export

PNG Export allows you to generate high-quality images of your collection.

The exported images are perfect for:

- Sharing on Discord
- Posting on Reddit
- Uploading to X (Twitter)
- Keeping personal backups
- Showing collection progress

---

## Available Export Modes

Three export modes are currently available.

| Mode | Description |
|-------|-------------|
| Entire Collection | Exports every Sprite |
| Missing Only | Shows only missing Sprites |
| Current Sprite | Exports only the selected Sprite |

---

## Entire Collection

This option creates a complete overview of your collection.

Included information:

- Sprite artwork
- Owned variants
- Missing variants
- Completion status
- Mastered indicator
- Statistics

Recommended for:

- Full collection showcases
- Social media
- Personal archives

---

## Missing Only

Shows only the content you still need to collect.

Useful for:

- Planning your next objectives
- Quickly identifying missing Sprites
- Farming sessions

---

## Current Sprite

Exports only the currently selected Sprite.

The image includes:

- Artwork
- Variants
- Passive Ability
- Spawn Rates
- Completion

Ideal for:

- Discussions
- Guides
- Individual showcases

---

# 💾 JSON Backup

JSON Export creates a complete backup of your collection.

Unlike PNG Export, this option preserves every piece of data.

Saved information includes:

- Collected variants
- Mastered Sprites
- Statistics
- Preferences
- Filters
- View mode

The generated file can later be imported into Fortnite Sprite Locker.

---

## Creating a Backup

Creating a backup only takes a few seconds.

1. Open the Menu.
2. Select **Export JSON**.
3. Save the generated file.

Your collection is now safely backed up.

> 💡 **Tip**
>
> Create backups regularly, especially before clearing your browser data.

---

# 📥 JSON Restore

Previously exported collections can be restored at any time.

To import a backup:

1. Open the Menu.
2. Click **Import JSON**.
3. Select your backup file.
4. Confirm the import.

The application immediately restores every saved value.

No restart is required.

---

## Imported Data

The following information is restored:

| Data | Restored |
|-------|-----------|
| Collected Variants | ✅ |
| Mastered Sprites | ✅ |
| Preferences | ✅ |
| Filters | ✅ |
| Statistics | ✅ |

# 🔗 Share Collection

Share Collection is one of the application's most powerful features.

Instead of uploading files, the application generates a shareable URL containing your collection data.

Anyone opening the link can instantly view your collection.

No account is required.

No cloud server is used.

Everything happens locally.

---

## Creating a Share Link

To generate a share link:

1. Click **Share Collection**.
2. Wait for the link to be generated.
3. Copy the URL.
4. Send it to anyone.

The process takes only a few seconds.

---

## Opening a Shared Collection

When another user opens the generated link:

1. Fortnite Sprite Locker loads.
2. The embedded data is decoded.
3. The shared collection is restored.
4. The interface updates automatically.

No manual import is necessary.

---

# 🔐 Privacy

Fortnite Sprite Locker never uploads your data to external servers.

All exported information is generated locally inside your browser.

Your collection remains entirely under your control.

---

# ⚙️ How Sharing Works

Internally, the application:

1. Collects your current collection data.
2. Converts it into JSON.
3. Compresses and encodes the data.
4. Embeds it into the generated URL.

When someone opens the link, the reverse process automatically restores the collection.

```
Collection

↓

JSON

↓

Encoded URL

↓

Shared Link

↓

Decoded

↓

Collection Restored
```

# 💡 Best Practices

For the best experience:

- Export a JSON backup regularly.
- Use PNG Export for screenshots.
- Use Share Collection for friends.
- Keep backups after major updates.

# ❗ Troubleshooting

## PNG Export is incomplete

Ensure all images have finished loading before exporting.

---

## JSON Import failed

Verify that the backup file was created using Fortnite Sprite Locker.

---

## Share link doesn't work

Check that the complete URL has been copied.

Some messaging platforms may truncate very long links.

---

## My collection disappeared

Restore your latest JSON backup.

If no backup exists, LocalStorage may have been cleared.
