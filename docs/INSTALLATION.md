# 📥 Downloading the Project

There are multiple ways to obtain Fortnite Sprite Locker.

---

## Option 1 — Download ZIP

The easiest method.

1. Open the GitHub repository.
2. Click **Code**.
3. Select **Download ZIP**.
4. Extract the archive anywhere on your computer.

You are now ready to launch the application.

---

## Option 2 — Clone with Git

If you use Git, clone the repository:

```bash
git clone https://github.com/USERNAME/fortnite-sprite-locker.git
```

Replace `USERNAME` with the repository owner's GitHub username.

This method is recommended if you plan to receive future updates or contribute to the project.

---

# 📂 Folder Structure

After downloading the project, your directory should look similar to this:

```text
fortnite-sprite-locker/
│
├── index.html
├── assets/
├── screenshots/
└── docs/
```

Ensure that the `assets/` folder remains in the same location as `index.html`.

Moving or renaming folders may prevent images and audio from loading correctly.

---

# ▶️ Running the Application

Starting Fortnite Sprite Locker is incredibly simple.

1. Navigate to the project folder.
2. Double-click `index.html`.

Alternatively, drag the file into your web browser.

The application will open immediately.

No installation wizard is required.

# 💾 LocalStorage

The application automatically stores your collection using your browser's LocalStorage.

This means:

- Your progress is saved automatically.
- No internet connection is required.
- No account is needed.
- No cloud synchronization occurs.

> 💡 **Tip**
>
> Export a JSON backup regularly if your browser data may be cleared.

---

# 🔄 Updating

Updating to a newer version is straightforward.

1. Download the latest release.
2. Replace the application files.
3. Keep your existing LocalStorage or import a JSON backup if necessary.

Always read the latest `CHANGELOG.md` before updating.

# ❗ Troubleshooting

## Images are missing

Verify that the `assets/` folder is located next to `index.html`.

---

## Music doesn't play

Some browsers require user interaction before playing audio.

Simply click anywhere inside the application.

---

## My progress is gone

Check whether your browser data has been cleared.

If available, restore your collection using a JSON backup.

---

## The application doesn't open

Ensure that JavaScript is enabled in your browser.

Try opening the file in a different browser if the issue persists.

---

# 💡 Best Practices

For the best experience:

- Keep the folder structure unchanged.
- Do not rename image files.
- Use an up-to-date browser.
- Export JSON backups regularly.
- Download new releases from the official repository.
